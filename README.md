# Backend Playground
A collection of backend and API projects built with Python. The main goal of this repository is learning, experimentation, and exploring real-world backend practices.


## Project 1 includes:

* Basic Book API endpoints
* HTTP methods: GET, POST, PUT, DELETE
* In-memory data storage
* Simple filtering (by author and category)
* Basic request handling
* Manual data manipulation without validation framework


## Project 2 includes:

* Creating Book API endpoints
* HTTP methods: GET, POST, PUT, DELETE
* Data validation
* Exception handling
* HTTP status codes
* `model_config` for Swagger documentation
